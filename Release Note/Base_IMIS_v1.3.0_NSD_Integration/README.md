# Base IMIS v1.3.0 - NSD Integration Review Package

This folder contains the Markdown release documents, workflow diagrams, one-page information sheet, and the linked Base IMIS User Manual for the NSD integration update.

## Review Steps

1. Open the `Base_IMIS_v1.3.0_NSD_Integration` folder.
2. Keep the complete folder structure unchanged.
3. Open the folder in Visual Studio Code.
4. Open `Base_IMIS_v1.3.0_NSD_Integration_Release_Notes_Final.md`.
5. Press `Ctrl + Shift + V` to preview the Markdown file.
6. Click **User Manual** in Section 8, or open the Base IMIS User Manual directly from the `documents` folder.
