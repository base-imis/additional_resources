# Additional Resources
This repository includes a variety of resources to support the implementation and understanding of IMIS:  

- [**Readiness Assessment Resource Materials**](https://github.com/base-imis/other_resources/blob/main/Readiness%20Assessment.pdf): Resource materials to evaluate readiness of a city for deploying IMIS.
  
- [**Field Survey Questionnaire**](https://github.com/base-imis/other_resources/blob/main/Building%20Questionnaire.pdf): A template survey questionnaire for collecting building-related data during field surveys.
  
- [**Resource Materials for GIS Data Collection**](https://github.com/base-imis/additional_resources/tree/main/GIS%20Data%20Creation%20Resource%20Materials): Resource materials for collecting GIS data for IMIS.
  
- [**CWIS Plan using IMIS**](https://github.com/base-imis/additional_resources/blob/main/CWIS%20Planning%20using%20Base%20IMIS.pdf): A reference materials for CWIS based planning using IMIS.
  
- [**IMIS Brochure**](https://github.com/base-imis/additional_resources/blob/main/IMIS%20Brochure.pdf): A concise visual overview of IMIS.
  
- [**IMIS Poster**](https://github.com/base-imis/additional_resources/blob/main/IMIS%20Poster.pdf): A visual summary of IMIS.
  
- [**IMIS Logo - Standard**](https://github.com/base-imis/additional_resources/blob/main/IMIS%20Logo%20-%20Standard.png): The official IMIS logo in its standard format.
  
- [**IMIS Logo - Inverted**](https://github.com/base-imis/additional_resources/blob/main/IMIS%20Logo%20-%20Inverted.png): The IMIS logo in an inverted color scheme.
